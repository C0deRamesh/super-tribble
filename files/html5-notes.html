HTML5 Notes

HTML5 (HyperText Markup Language version 5) is the latest standard language used to create web pages and web applications. It gives a webpage its basic structure through elements called tags.

HTML is not a programming language; it is a markup language used to organize and display text, images, videos, links, tables, and forms.

Features of HTML5

  • Simple, clean syntax and semantic elements
  • Audio, video, canvas, and SVG support
  • Local Storage, Geolocation, Drag and Drop, Web Workers, and WebSockets
  • Responsive design support and better form validation

Basic HTML structure

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Website</title>
</head>
<body>
  <h1>Hello World</h1>
</body>
</html>

Tags, elements, and attributes

Tags tell the browser what to display. An element has an opening tag, content, and a closing tag.

<h1>Heading</h1>
<p>Hello Students</p>
<a href="https://google.com">Google</a>
<img src="image.jpg" alt="Image">

Common attributes

id, class, href, src, alt, style, title, and target.

Text content

Headings and paragraph

<h1>Main Heading</h1>
<h2>Heading</h2>
<h6>Heading</h6>
<p>This is paragraph.</p>

Text formatting

<b>Bold</b>        <strong>Important</strong>
<i>Italic</i>      <em>Emphasis</em>
<u>Underline</u>   <mark>Highlight</mark>
<small>Small Text</small>  <del>Deleted</del>
<ins>Inserted</ins>  <sub>Subscript</sub>  <sup>Superscript</sup>

Lists, links, images, and tables

<ol><li>HTML</li><li>CSS</li></ol>
<ul><li>HTML</li><li>CSS</li></ul>

<a href="https://google.com" target="_blank">Google</a>
<img src="photo.jpg" alt="Nature" width="300">

<table border="1">
  <tr><th>Name</th><th>Age</th></tr>
  <tr><td>Ramesh</td><td>20</td></tr>
</table>

Forms and input types

<form>
  <input type="text">
  <input type="email">
  <input type="password">
  <input type="submit">
</form>

Input types include: text, password, email, number, date, time, color, range, radio, checkbox, file, submit, reset, and button.

<button>Click Me</button>

Div, span, and semantic tags

A div is a block-level container. A span is an inline container.

<div><h2>Title</h2><p>Content</p></div>
<p>Hello <span>World</span></p>

<header><nav>Navigation</nav></header>
<main><section><h2>HTML Tutorial</h2></section></main>
<footer>Copyright 2026</footer>

Important semantic tags: header, nav, main, section, article, aside, and footer.

Media, iframe, entities, comments, and meta tags

<audio controls><source src="song.mp3"></audio>
<video controls width="500"><source src="video.mp4"></video>
<iframe src="https://example.com" width="500" height="300"></iframe>

<!-- This is a comment -->

<meta name="description" content="HTML Notes">

HTML5 APIs and Local Storage

HTML5 APIs include Geolocation, Drag and Drop, Local Storage, Session Storage, Web Workers, Canvas, and WebSockets.

localStorage.setItem("name", "Ramesh");
let user = localStorage.getItem("name");
localStorage.removeItem("name");

Best practices

  • Use semantic HTML and lowercase tag names.
  • Always add meaningful alt text to images.
  • Indent code properly and close every tag.
  • Organize content with headings and meaningful classes and IDs.
  • Keep HTML, CSS, and JavaScript in separate files.
  • Use the viewport meta tag, make pages responsive, and validate HTML.
