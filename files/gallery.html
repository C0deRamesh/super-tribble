◆ learning roadmap

Learn web development the simple way.

Study for 60–90 minutes a day. Read the notes, type every example yourself, then build the small task before moving on.

WEEK 1

Start with HTML5

Learn page structure, headings, links, images, lists, forms, and semantic tags. Spend 45 minutes learning and 30 minutes building a profile page each day.

WEEK 2–3

Make it beautiful with CSS

Practice selectors, box model, Flexbox, Grid, and responsive design. Rebuild the same profile page for mobile and desktop.

WEEK 4–5

Add JavaScript

Learn variables, conditions, functions, arrays, DOM, and events. Build a calculator or to-do list while writing the code yourself.

WEEK 6

Build and share

Combine HTML, CSS, and JavaScript into one small project. Test it on phone and desktop, fix issues, then add it to your portfolio.
