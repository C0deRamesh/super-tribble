JavaScript (ES6+) Notes

JavaScript (JS) is a high-level, interpreted programming language used to make web pages interactive and dynamic. It works with HTML for structure and CSS for style.

Why learn JavaScript?

  • Adds interactivity and dynamic content to web pages.
  • Handles user events and communicates with servers through APIs.
  • Builds web, mobile, and desktop apps; it is essential for frontend and backend development.

Features

Lightweight, object-oriented, event-driven, interpreted, cross-platform, dynamically typed, asynchronous, functional-programming support, and a huge npm ecosystem.

Best practices

  • Prefer let and const over var.
  • Use meaningful names, small focused functions, and avoid globals.
  • Use strict equality (===), validate input, and handle errors with try...catch.
  • Use modules and addEventListener(); comment only when necessary.

Interview questions and learning roadmap

Interview questions

  • What are the differences between var, let, and const, and between == and ===?
  • Explain closures, hoisting, the DOM, events, event bubbling/capturing, and the event loop.
  • What are promises, async/await, callbacks, and higher-order functions?
  • What is the difference between null and undefined, localStorage and sessionStorage, synchronous and asynchronous code?

Roadmap

JavaScript basics → variables and data types → operators and conditions → loops → functions → arrays and objects → DOM → events → ES6+ → JSON → storage → Fetch/AJAX → promises → async/await → error handling → modules → mini projects → object-oriented JavaScript → closures, event loop, prototypes, and memory management.
