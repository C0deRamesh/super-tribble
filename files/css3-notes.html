CSS3 Notes

CSS (Cascading Style Sheets) is a stylesheet language used to control the appearance and layout of HTML webpages.

CSS makes websites attractive, responsive, and user-friendly by styling colors, fonts, spacing, animations, and layouts.

Why use CSS?

  • Makes websites beautiful and separates design from content.
  • Creates reusable styles, responsive layouts, and easier maintenance.
  • External stylesheets can improve loading performance.

CSS syntax

selector {
  property: value;
}

h1 {
  color: blue;
  font-size: 40px;
}

Types of CSS

/* Inline CSS */
<h1 style="color:red;">Hello</h1>

/* Internal CSS */
<style>
h1 { color: blue; }
</style>

/* External CSS */
<link rel="stylesheet" href="style.css">
h1 { color: green; }

CSS selectors

* { margin: 0; padding: 0; }             /* universal */
p { color: red; }                         /* element */
.box { background: black; }                /* class */
#header { background: blue; }               /* ID */
h1, h2, p { color: purple; }                /* group */
div p { color: red; }                       /* descendant */
div > p { color: blue; }                    /* child */
h1 + p { color: red; }                      /* adjacent sibling */
h1 ~ p { color: green; }                    /* general sibling */
input[type="text"] { border: 1px solid black; } /* attribute */

Colors, backgrounds, fonts, and text

color: red;
color: #00ff00;
color: rgb(255, 0, 0);
color: rgba(0, 0, 0, .5);
color: hsl(220, 100%, 50%);

body { background: #f5f5f5; }
body { background-image: url(image.jpg); background-size: cover; background-repeat: no-repeat; }

p { font-family: Arial, sans-serif; font-size: 20px; font-weight: bold; font-style: italic; }
h1 { text-align: center; text-transform: uppercase; text-decoration: underline; letter-spacing: 2px; line-height: 2; }

Box model, sizing, and display

The CSS box model consists of content, padding, border, and margin.

.box { width: 300px; padding: 20px; border: 2px solid black; margin: 20px; }
div { width: 300px; height: 200px; }
margin: 20px;       margin: 20px 40px;       margin: auto;
padding: 20px;      padding: 10px 30px;
border: 2px solid red; border-radius: 10px;

display: block; display: inline; display: inline-block;
display: flex;  display: grid;   display: none;

Position, z-index, overflow, and float

position: static;
position: relative;
position: absolute;
position: fixed;
position: sticky;

.box { position: absolute; z-index: 100; }
overflow: hidden; overflow: auto; overflow: scroll;
float: left; float: right;

Flexbox and Grid

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 20px;
}
/* justify-content: center | start | end | space-between | space-around | space-evenly */
/* align-items: center | start | end | stretch */
/* flex-direction: row | column */

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 20px;
}

Effects and interaction

box-shadow: 0 10px 20px rgba(0,0,0,.2);
text-shadow: 2px 2px 5px gray;
opacity: .5;
cursor: pointer; cursor: not-allowed;

button { transition: .3s; }
button:hover { background: red; }
transform: scale(1.2); transform: rotate(45deg);
transform: translateX(50px); transform: skew(20deg);

.box { animation: move 2s infinite; }
@keyframes move { from { transform: translateX(0); } to { transform: translateX(200px); } }

Pseudo-classes include :hover, :focus, :first-child, :last-child, and :nth-child(). Pseudo-elements include ::before, ::after, ::first-letter, and ::first-line.

Variables, responsive design, and modern effects

:root { --primary: #2563eb; --secondary: #9333ea; }
button { background: var(--primary); }

@media (max-width: 768px) {
  .container { flex-direction: column; }
}

background: linear-gradient(to right, #4f46e5, #9333ea);

.card {
  background: rgba(255,255,255,.1);
  backdrop-filter: blur(15px);
  border: 1px solid rgba(255,255,255,.2);
  border-radius: 20px;
}

Useful units: px, %, em, rem, vw, vh, and fr.

Responsive design and best practices

  • Use Flexbox and Grid; avoid fixed widths where possible.
  • Use rem for fonts, optimize images, and test different screen sizes.
  • Use external CSS, simple selectors, meaningful class names, and CSS variables.
  • Avoid excessive !important; group and comment related styles.
  • Minify CSS for production.

CSS interview questions

  • What is CSS and what are its different types?
  • What is the CSS Box Model? What is the difference between margin and padding?
  • Explain Flexbox, Grid, and the difference between inline, block, and inline-block.
  • How do position: relative and position: absolute differ?
  • What are pseudo-classes, pseudo-elements, CSS variables, and media queries?
  • What is the difference between em and rem?
  • How do the cascade, specificity, z-index, and stacking contexts work?
  • What is the difference between display: none and visibility: hidden?
